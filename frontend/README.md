# Frontend - Papel y Luna POS

Sistema de punto de venta (POS) para papelería Papel y Luna.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:5173`

## Build

```bash
npm run build
```

## Módulos Implementados

- ✅ Autenticación y Sesión
- 🔄 Módulo de Ventas (POS/Caja)
- 🔄 Módulo de Inventario
- 🔄 Módulo de Compras
- 🔄 Módulo de Faltantes
- 🔄 Gestión Administrativa
